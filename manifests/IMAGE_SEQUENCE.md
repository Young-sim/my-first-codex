# STAGE 2 — Scene and Keyframe Plan

## 기준

- **승인 내레이션:** `script/APPROVED_NARRATION_KR.md` (변경 없음)
- **TTS 음성:** Vrew 다현 1 (빠르게)
- **실제 TTS 길이:** 86초 (`01:26`)
- **화면비:** 세로 `9:16`
- **소스 클립 길이:** 키프레임당 4초
- **계획 수량:** 25개 장면 / 25개 CLEAN–INFO 키프레임 쌍 / 25개 소스 클립
- **예상 소스 분량:** 100초 (`25 × 4초`); 최종 편집에서 실제 86초 TTS에 맞춰 각 클립의 약 1.5–4초를 사용

## 편집 및 증거 원칙

1. 아래 구간은 실제 86초 TTS의 총길이에 맞춘 편집 기준이다. 최종 음성 파형에서 각 문장의 실제 시작점과 끝점에 컷을 스냅하되, 장면 순서와 승인된 내레이션은 바꾸지 않는다.
2. 범람 장면과 줄·말뚝 측량 장면은 동일한 밭의 ‘전후 복원 과정’처럼 연결하지 않는다.
3. 멘나의 무덤, 윌버 파피루스, 린드 수학 파피루스는 각각 도상·행정 기록·수학 문헌이 입증하는 범위만 표현한다.
4. 헤로도토스 구간은 앞선 이집트 자료보다 후대의 문헌적 기원 설명임을 시간축과 시각 스타일로 구분한다.
5. INFO는 개념 수준의 오버레이 계획일 뿐이다. 이 단계에서는 CLEAN 또는 INFO 생성 프롬프트를 작성하지 않는다.
