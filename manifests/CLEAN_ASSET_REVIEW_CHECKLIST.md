# STAGE 4 — CLEAN Asset Review Checklist

## 현재 검수 상태

- 사용자가 외부에서 생성했다고 보고한 이미지: **29개**
- 승인된 정식 Keyframe 슬롯: **25개**
- 재생성본·추가 이미지: **4개**
- 현재 저장소의 `clean/`에서 실제로 확인 가능한 이미지: **0개**
- 현재 판정: **사용자 검수 완료 — 정식 25개 승인, EXTRA 4개 시퀀스 제외**

사용자가 실제 생성 결과를 검수하고 정식 25개 CLEAN 키프레임을 최종 승인했다. 저장소에서는 바이너리 이미지를 직접 열어 재검증하지 못했으므로 아래 상태는 `USER APPROVED`로 기록하며, 로컬 시각 검수를 수행했다는 의미로 바꾸지 않는다. 추가 생성된 4개는 정식 시퀀스에서 제외한다.

## 검수 절차

1. 생성된 원본 29개를 삭제하거나 덮어쓰지 않은 상태로 `clean/`에 제공한다.
2. 파일명과 생성 시각만으로 정식본을 선택하지 않는다. 각 파일을 실제로 열어 시각 내용을 확인한다.
3. 먼저 25개 승인 슬롯에 대응할 후보를 Scene ID / Keyframe ID별로 모은다.
4. 같은 ID의 후보가 둘 이상이면 모두 재생성본 후보로 보존하고, 승인 프롬프트 적합성을 비교한 뒤 하나만 `OFFICIAL`로 지정한다.
5. ID가 없거나 잘못된 파일은 시각 내용으로 대응 장면을 판별한다. 판별할 수 없으면 추측하지 않고 `UNMAPPED`로 남긴다.
6. 각 정식 후보에 대해 파일 무결성, 9:16 화면비, 실제 장면 내용, 역사성, CLEAN 금지 요소, 연속성을 확인한다.
7. 결함이 특정 이미지에만 있으면 해당 Keyframe ID만 재생성 대상으로 표시한다. 전체 배치 재생성을 요청하지 않는다.
8. 25개 슬롯이 모두 통과하고 재생성본 4개의 지위가 정리된 뒤에만 STAGE 4 완료로 판정한다.

## 모든 이미지에 적용하는 공통 판정 항목

### 파일 및 형식

- [ ] 파일이 열리고 손상되지 않았다.
- [ ] 정확한 Scene ID / Keyframe ID에 대응한다.
- [ ] 세로 화면이며 실제 픽셀 비율이 `9:16`이다. 권장 해상도는 `1080×1920` 이상이다.
- [ ] 콜라주, 스토리보드, 접촉 시트, 분할 화면이 아닌 하나의 연속 장면이다.
- [ ] 전경·중경·배경 깊이가 있어 이후 5–15도 카메라 이동이 가능하다.

### CLEAN 금지 요소

- [ ] 문자, 단어, 자막, 숫자, 날짜, 공식, 판독 가능한 상형문자·히에라틱·그리스 문자가 없다.
- [ ] 화살표, 콜아웃, 측정선, 눈금, 도표, 차트, 지도, 타임라인, 격자, UI, HUD가 없다.
- [ ] 로고, 서명, 워터마크, 생성 모델 표식이 없다.
- [ ] 인포그래픽 발광, 네온, 마법 효과, 공중에 뜬 기하 도형이 없다.

### 역사성 및 물리성

- [ ] 고대 이집트 장면의 복식·도구·농경 환경이 시대에 맞고 과장된 왕실·할리우드식 장식이 없다.
- [ ] 현대 측량기, 금속 줄자, 광학 레벨, 삼각대, 현대 농기계·건물·콘크리트 시설·플라스틱이 없다.
- [ ] 물, 토사, 침식, 퇴적과 식생의 상태가 물리적으로 자연스럽다.
- [ ] 피라미드·거상·오벨리스크가 평범한 농경 장면의 장식적 배경으로 남용되지 않았다.
- [ ] 신체·손·도구·줄이 변형되거나 중복되거나 서로 관통하지 않는다.
- [ ] 확인되지 않은 ‘범람 직후 경계 복원 절차’를 실제 사건처럼 보여 주지 않는다.

### 연속성

- [ ] `KF-01A`–`KF-08B`는 나일 범람원, 토양, 물, 날씨와 색감이 서로 양립한다.
- [ ] `KF-09A`–`KF-13A`는 고대 이집트 증거·재현 장면으로서 복식과 재료가 이어진다.
- [ ] `KF-14A`–`KF-14C`의 후대 그리스 문헌 구간은 앞선 이집트 자료와 시대가 분명히 구별된다.
- [ ] `KF-15A`–`KF-15C`는 확인된 증거와 단일 원인설의 한계를 시각적으로 혼동시키지 않는다.
- [ ] 인접 장면에서 동일 인물·도구·환경을 의도치 않게 다른 형태로 바꾸거나 복제하지 않는다.
